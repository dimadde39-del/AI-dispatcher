# 05. Объем MVP (Scope)

Самый важный анти-бредовый файл. Мы строим великолепный позор инженерии на первые 14 дней, а затем переводим на жесткий self-host.

## Входит в MVP v0.1 (Первые 14 дней - Тест гипотезы):
* [x] Один виртуальный номер (SIP/Twilio/Zadarma).
* [x] **Двойная переадресация** (**61* на 15 сек и **67* при сбросе).
* [x] AI-голос на русском языке (Используем **Vapi.ai** только для быстрого старта на 14 дней).
* [x] Мягкий легальный промпт: *"Я электронная помощница, запишу вашу проблему..."*.
* [x] Telegram-карточка лида (приходит в ТГ мастеру).
* [x] Лог звонков в базе данных (Supabase).
* [x] Ручная настройка мастера (без UI для регистрации).

## Входит в v1.0 (После 14 дней - Выход в плюс):
* [x] **Self-host архитектура:** Twilio + Deepgram + GPT-4o-mini + Azure TTS (Снижение COGS до ~1,650₸/мес).
* [x] **Локализация:** База данных переезжает в Beeline Cloud (Казахстан) для соблюдения закона о ПДн.
* [x] **ИП на упрощенке:** Легальный прием платежей.
* [x] **Отчеты о ценности (Value-Reminders):** Каждое воскресенье бот присылает мастеру сообщение: *"За неделю я спасла вам 3 заказа на ~30,000₸"*. (Защита от оттока).
* [x] Цена: **5,000₸ в месяц** flat (Никаких 20-30 тысяч).

## НЕ входит (Пока нет 10+ платящих мастеров):
* [ ] Полноценная CRM с воронками продаж.
* [ ] Маркетплейс для клиентов.
* [ ] AI, который называет точные цены или дает гарантии.
* [ ] 24/7 Human Support.
