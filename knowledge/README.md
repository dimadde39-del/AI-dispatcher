# Knowledge System

This folder is the project memory for AI Dispatcher. It keeps product intent, architecture decisions, current state, open questions, and source material available to future Codex tasks.

Use it as a lightweight operating system:

- `CURRENT_STATE.md` tracks the current phase and meaningful decisions.
- `PRODUCT_BRIEF.md` explains what the product is and is not.
- `ARCHITECTURE.md` defines boundaries and core entities.
- `TASKS.md` lists implementation milestones.
- `OPEN_QUESTIONS.md` records unresolved product and technical questions.
- `VALIDATION.md` describes expected checks.
- `GUARDRAILS.md` captures safety and legal constraints.
- `raw/` stores canonical uploaded source documents.
- `wiki/` stores agent-maintained summaries and synthesis.
- `decisions/` stores ADRs.
